# Як підключити Google Drive (ЛР 2*)

Програмі потрібен файл `client_secret.json` — ключ OAuth-клієнта Google. Він має лежати тут:

```
IndividualWork.App\Resources\Raw\client_secret.json
```

Якщо ви вже робили ЛР1*, підійде той самий файл: скопіюйте його з `MyExcelMAUIApp\Resources\Raw\` і перезберіть проєкт.

## Якщо ключа ще немає

1. Відкрийте https://console.cloud.google.com/ і створіть проєкт (**New project**).
2. **APIs & Services → Library** → знайдіть **Google Drive API** → **Enable**.
3. **APIs & Services → OAuth consent screen** → **Get started**: назва застосунку, ваша пошта, тип **External**.
4. Розділ **Audience** → **Test users** → **Add users** → додайте свій Gmail. Без цього Google не пустить у застосунок.
5. **Clients** → **Create client** → тип **Desktop app** → **Create** → **Download JSON**.
6. Перейменуйте файл на `client_secret.json`, покладіть у папку вище, перезберіть проєкт.

## Перший запуск

Після першої дії з Google Drive відкриється браузер. Увійдіть акаунтом із *Test users*, на попередженні «Google hasn't verified this app» натисніть **Continue** і дозвольте доступ. Далі вхід запам'ятовується; у режимі тестування Google просить увійти знову приблизно раз на 7 днів.

## Що програма бачить на диску

Використовується доступ **`drive.file`**: програма бачить і змінює **лише файли, які сама створила**. Тому, щоб відкрити XML або XSL із Google Drive, спочатку збережіть їх туди кнопкою **«Зберегти вхідні файли на Drive»**. Файл, який ви поклали на диск вручну через браузер, програма не побачить.

Файл із тією самою назвою під час збереження оновлюється, а не дублюється.

## Безпека

`client_secret.json` — секрет вашого проєкту Google. Він виключений у `.gitignore`; не викладайте його в публічний репозиторій.

## Якщо щось не працює

| Повідомлення | Що робити |
|---|---|
| «Не знайдено файл client_secret.json…» | Перевірте назву й папку, перезберіть проєкт |
| «Error 403: access_denied» у браузері | Вашу пошту не додано в *Test users* |
| «Google не надав доступ…» | Увійдіть знову; якщо повторюється — створіть ключ заново |
| «Немає з'єднання з Google Drive…» | Перевірте інтернет |
